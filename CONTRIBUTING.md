# Contributing

Focused bug reports and pull requests are welcome.

1. Create a branch from the default branch.
2. Add tests for every behavioral change.
3. Run `devtools::document()`, `devtools::test()`, and `devtools::check()`.
4. Update tutorials when public behavior changes.
5. Use synthetic, public, or fully anonymized text in tests and examples.

Do not add functions that install packages or silently change a user's files,
options, working directory, or random-number state.
